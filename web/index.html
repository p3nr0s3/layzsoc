              LazySOC
              v3.0 SOC
            

            
Zero-Effort Automated Threat Intelligence Triage & Security Workbench

          

        

        
      


      

        

          LazySOC is a lightweight, high-performance Security Operations Center (SOC) workbench built for security analysts, incident responders, and threat hunters. It eliminates manual triage fatigue by aggregating threat telemetry, analyzing suspicious artifacts, and generating actionable escalation notes with zero friction.
        


        

          Core Capabilities
          

            

              
                 Multi-IoC Triage
              
              
Defangs & scores mixed IPs, domains, hashes, and URLs via VirusTotal & AbuseIPDB.

            

            

              
                 Network Recon
              
              
Passive Shodan exposure, open ports, ASN routing, reverse DNS, and host banners.

            

            

              
                 Phishing EML Forensics
              
              
Hop routing inspection, SPF/DKIM/DMARC auth, payload hashes, and defanged link extractor.

            

            

              
                 Domain Mail Health
              
              
Audits MX records, SPF policy mechanisms, and spoofing vulnerability posture.

            

            

              
                 Live Threat Feeds
              
              
Paginated real-time security alerts from The Hacker News, BleepingComputer, CISA, Krebs.

            

            

              
                 Live Online CVE / NVD
              
              
Direct online API lookup to NIST NVD 2.0 & CISA KEV. Zero local database bloat.
